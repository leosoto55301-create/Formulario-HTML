Formularios en HTML

Texto

Campos de texto basicos: simple, con placeholder, obligatorio (required), de solo lectura (readonly) y deshabilitado (disable).
Contacto

Campos especializados para datos de contacto: contrase;a, correo electronico, telefono y URL, cada uno con su propio teclado y validacion en el navegador.





Numericos

Campos para valores numericos: un numero con limites (min/max) y un deslizador (range) para elegir un valor dentro de un rango.



Fecha y hora

Selectores nativos de fecha y hora: fecha, fecha y hora combinadas, hora, semana del año y mes.





Seleccion

Controles de seleccion: elegir un color, marcar una casilla, elegir una opcion de un grupo de radios y subir un archivo.




Listas desplegables (select)

Listas desplegables con el elemento selecto: una opinion simple, una con valor preseleccionado (selected) una agrupada con optgroup, una de seleccion multiple (multiple) y una deshabilitada (disabled).
